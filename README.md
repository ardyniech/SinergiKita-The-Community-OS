# SinergiKita: Community Operating System

SinergiKita is a comprehensive, grassroots-first platform designed to democratize community administration. It provides community leaders and members with powerful tools to manage finances, social welfare, security, and communication in a transparent and efficient manner.

## 🚀 Features

-   **Dashboard Analytics**: Real-time overview of community health and financial status.
-   **Finance Module**: Transparent budget management, recurring billing (maintenance/iuran), and financial audit trails.
-   **Social Welfare (Info Santunan)**: Crowdsourced support for members in need, ensuring no neighbor is left behind.
-   **Emergency SOS System**: Real-time security alerts with prioritized notifications for the entire community.
-   **Secure Member Directory**: Role-based access to community contact information and skill sets.
-   **AI Community Insights**: Weekly executive summaries and actionable recommendations powered by Google Gemini.
-   **Smart Notifications**: Keep everyone informed with announcements and real-time updates.

## 🛠️ Technical Stack

-   **Frontend**: React 19, Vite, Tailwind CSS, Framer Motion (Motion).
-   **Backend**: Node.js (Express), Server-side Gemini API Integration.
-   **Database**: Firebase Firestore (Real-time sync).
-   **Authentication**: Firebase Auth.
-   **AI**: Google Gemini AI (1.5 Flash).

## 📦 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/sinergikita-community-os.git
    cd sinergikita-community-os
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Environment Setup**:
    Create a `.env` file based on `.env.example` and add your `GEMINI_API_KEY`.

4.  **Run Development Server**:
    ```bash
    npm run dev
    ```
