# Project UI Standards

- **Compactness**: The UI must be high-density and professional.
- **Spacing Constraints**:
  - Maximum padding: `p-5` (1.25rem).
  - Maximum margin: `m-5` (1.25rem).
  - Maximum gap: `gap-5`.
  - Maximum vertical spacing: `space-y-5`.
- **Border Radius**: Avoid "jumbo" or "bubbly" looks. Use `rounded-xl` or `rounded-2xl` instead of `rounded-[40px]` or `rounded-3xl`.
- **Typography**: Use tight tracking and appropriate font weights to ensure clarity without excessive whitespace.
